Documentation · version 0.1.0

Validation & limitations

Investigated on 25 October 2026. Current inference uses WeVisOne-VL-4B only. The evaluated 2B model and selection option were removed at the user's request; historical measurements remain in ignored local results.

Implementation choices

The official WeVisOneVL.predict(task="segmentation") API returns boxes and pixel probabilities. The required mask_decoder.pt is part of the model; a generic text-only pipeline does not supply masks. We use the official trained prompt template, Transformers backend, temperature zero and a default 0.5 probability threshold. No separate SAM pipeline is required.

Upstream code is pinned to 40f735b8daed437ece982db9718e9c9856f52a79; 4B weights to 4a7bed92750ac9d8b8a124cede14759036932dc2. The device-independent PyTorch decoder runs on Windows without custom CUDA compilation, FlashAttention or vLLM. Python 3.12 is required by upstream SciPy 1.18.1. The environment uses PyTorch 2.11.0+cu126 and Transformers 5.12.1; dependency checks pass.

Output conventions follow cisegmentation v0.6.6. A separate engine avoids bringing Cellpose/StarDist dependencies into this environment. No microscopy training or fine-tuning was performed. Upstream benchmarks do not establish microscopy accuracy.

Initial public data

The five initial examples are genuine 2D images, converted to NGFF 0.4/Zarr v2 with T=Z=1. RGB is stored as separate channels. Full-resolution values are unchanged; pyramids use area averaging. Originals, OME-XML, checksums and attribution remain local.

Observed behavior

The RTX A5000 has 24 GB VRAM. The initial matrix peaked near 11.6 GiB of PyTorch-allocated memory, excluding desktop/driver allocations. After loading, a cell query took about 2 seconds and the 83-object organoid query about 45 seconds. These are local workstation measurements, not Slurm/HPC benchmarks.

Invalid responses and absence

A dense exploratory query generated 118 object tokens but only 116 valid boxes, including reversed coordinates. The upstream decoder filters invalid boxes and then uses the first N object representations, which can misalign them. This adapter checks correspondence before decoding and preserves invalid responses for diagnosis. It never invents, swaps or silently skips object coordinates.

The negative query elephant returned <ref>elephant</ref><box>none</box>, accepted as a valid empty mask. This supports that specific negative control, not general reliable microscopy rejection: an absent organoid query on nuclei instead produced a large false-positive mask.

Projection, time series and HCS

The advanced projection option offers Max by default and Mean. Z stacks are reduced per channel, timepoint and screen field. Timepoints are never merged. Max retains dtype; Mean writes float32. Projection pyramids are rebuilt from the projected image. Existing 2D pixel values remain unchanged.

Outputs use TCZYX with Z=1; labels use C=Z=1. Source-volume physical Z position is omitted while XY/time transforms remain intact. OME-XML is updated to SizeZ=1 and to float for Mean. Existing volume labels remain in the untouched source.

Derived fixtures have distinct T/Z values. A GPU fixture with two fields, two timepoints and three Z planes uses a shifted public phase-cell image. Exact projection values, unchanged sources and label movement were checked. This validates data handling, not independent biological 3D accuracy.

The installed ZarrReader incorrectly read timepoints as zero from compact TCYX arrays. Output was therefore changed to the five-axis cisegmentation layout. The corrected reader matched all 48 checked image/label windows across both projections, fields, timepoints and resolutions. Failed and corrected probes remain in separate ignored local result directories.

Measurements and descriptor

One CSV covers all inputs, fields, timepoints and prompts. It stores shape, area/position and min/max/mean/total intensity plus a valid count for every channel. Positive NGFF XY calibration enables area in µm² and perimeter, diameter, axes, centroid and bounding-box coordinates in µm, alongside pixel references. Dataset and global transforms are composed in order, including origins and unit conversion. Anisotropic axes use physical moments; anisotropic perimeter uses scaled closed contours. The estimator and shape basis are recorded. Unknown calibration leaves physical columns blank. Measurements use original 2D pixels or the projection before normalization.

34 tests pass, covering a fourth real fluorescence channel, varying channel counts, time/label correspondence, calibration, failed runs and descriptor fields. Calibration tests include isotropic and unequal X/Y spacing, nanometer-to-µm conversion, physical shape axes and ordered global/dataset transforms. Actual 4B Max/Mean runs each wrote four rows; measurements matched output pixels. The installed BIOMERO adapter validated one CSV measurement output and the correct workflow name/description. The first citation entry supplies these fields. A live OMERO attachment import remains for the later Docker/Slurm phase.

Expanded collection and published masks

The collection has 27 examples, including 22 additions: 14 separate 2D images, 6 Z stacks and 2 time series, about 206 MB of OME-Zarr input. Original WSI files, archives and EM chunks remain separate. Local copies were checked with SHA-256; conversions checked written values. All examples pass preflight.

Examples include spines, neurites, vessels, organoid tissue, adipocytes, skin, plant vascular bundles, diatoms and embryos. Complete acquired CMU-1, prostate and Ki67 scans use existing lower pyramid resolutions; the DAB detail is a recorded native ROI. CellMap COS-7 and liver FIB-SEM each provide a contiguous volume and middle 2D section; MIB supplies another mitochondrial EM example. The catalog preserves sources, selections, resolutions, channel counts and licenses.

Every example was processed again with its prompts and all timepoints: 64 label runs: 63 technically completed, 1 rejected. organoids_im9 generated 210 object tokens but 209 valid boxes; no completed mask was published. Nine completed runs have an empty first-frame mask. Empty output is not proof that a target structure is absent.

The gallery includes actual overlays, prompts, channels, coverage, source links, uint32 labels with time indices (NPZ) and CSV measurements. Cards show the first timepoint; downloads contain all available frames. "Computed" and "completed" describe execution, not biological correctness. Performance remains variable on ultrastructure, dense objects and staining patterns.

Automated launcher/process tests passed. Native Windows visual inspection was unavailable because desktop access was denied; the website is tested separately in the browser. Public assets are small derived previews and masks. Full stores, models, local workstation paths and raw logs are excluded. Docker recipes are prepared but no new image has been built or deployed; reader checks are not a live OMERO database import.

Follow-up prompt curation and tiling study

The first curation phase replaced the initial all-results presentation with 15 positively selected examples and 18 reviewed labels. It excludes all EM Z projections, empty outputs and unconvincing predictions. Source stores and all original experiments remain local. This curation must not be interpreted as a representative accuracy estimate.

The prompt comparison report documents 52 candidates: 28 descriptions on fixed fluorescence/DAB views and 24 on 8 native 2D EM patches. 33 paired CEM-MitoLab images/annotations were retrieved via ZIP byte ranges and CRC verification, without downloading the full 2.95 GB archive. Two retained EM patches score foreground Dice about 0.965 and 0.936. They share an acquisition and were selected after comparison, so they are not an independent test set.

Concrete appearance descriptions improve the green vessel profile and plant vascular bundles. A recorded native 192 × 192 Ki67 ROI with “dark brown stained nuclei” distinguishes positive brown nuclei from blue negatives. The white filament query demonstrates network foreground rather than complete axon tracing. Fluorescence/DAB improvements are qualitative because no manual masks were supplied.

The tile study reports real 512/768/1024-pixel GPU runs against 87 consensus organoid instances. Nominal 768/192 gave Dice 0.917 and instance F1 0.939 at IoU ≥ 0.5, compared with 0.881/0.906 for the earlier whole-image run. Actual edge overlap exceeds nominal overlap. These results do not establish general large-tilescan support or universal optimal settings.

There are now 39 passing tests: 34 workflow tests and 5 experimental stitching tests. They cover crossing objects, four-tile junctions, touching neighbors, ambiguous matches, odd edges and the prototype memory guard. The production 16-megapixel limit remains until the full IO/projection/storage/measurement pipeline becomes bounded. No new Docker image or BIOMERO deployment was built.

Whole/part modality follow-up and simpler controls

The modality comparison adds 37 candidate descriptions on nine prepared 2D views. Seven new views and eleven labels were retained: two phase-contrast Paramecium panels, chloroplast TEM, endothelial fluorescence, a native kidney optical section, and two insulin IHC views. The current gallery contains 22 positively selected examples and 29 labels after 89 candidate queries across the two studies. These new views have no manual reference masks. IHC cell-level and several kidney substructure queries remain unreliable and are excluded rather than presented as validated segmentations.

Final retained masks were rerun through the actual workflow with descriptive label names. All eleven new labels preserved source pixels exactly and produced 46 CSV rows; calibrated areas were checked against pixel counts and XY spacing. Raw arrays, all experiments and publication source images remain local.

Fresh descriptor/CLI defaults now use blank prompts and target1 through target4. The launcher honors advanced descriptor flags and collapses that panel initially. Channel inputs select one grayscale channel or three explicit RGB channels for each target; the renamed intensity-scaling control changes only their contrast. The 39-test suite also checks the generic defaults and advanced panel visibility/value retention.
